DYNASTY TRADE TREE — INSTALLABLE PWA

Publish:
Upload every file in this ZIP to any static HTTPS host (Netlify, GitHub Pages, Cloudflare Pages, Vercel).

Install on iPhone:
1. Open the hosted URL in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Tap Add.

It will launch from the Home Screen in its own standalone app window.

The league data is embedded in index.html. The service worker caches the app for offline use after the first successful load.
